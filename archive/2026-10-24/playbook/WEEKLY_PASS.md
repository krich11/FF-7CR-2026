# Weekly strategy pass

Ken wants every scoring week run through the same lenses. Assistant writes the facts. Blitz writes the card. Ken approves roster moves. Consultant reviews when Ken opens the Consultant chat.

This is a checklist. It is not a promise of a perfect week.

## Lenses

1. Ambulance chase — who inherited work, and are they free in this league
2. Own-star backup — skip the handcuff if our starter is back soon
3. Other-team backup — chase Hall/Allen type adds
4. Implied totals — high total = pass; low total = run and DST
5. Game script — big underdog running backs get a lower floor
6. Start studs — London, Wilson play if active
7. Opportunity — snaps and targets over last week's touchdowns
8. High-leverage touches — goal line and red zone
9. Thursday short week — DST and sloppy offense
10. One DST — extra defense is a bench tax after lock
11. Weeks 15–17 — break ties on the playoff slate
12. Stand still — no claim if the add is thin
13. Do not wake LY before the Wednesday run
14. Brissett stays. Never trade him.

## Clock

| When | Who | What |
|---|---|---|
| Sunday night after the last early window | Assistant | Injury tree + inheritors. Who is still free. |
| Monday after MRI / practice | Assistant | Update availability. Flag own-star vs other-team backups. |
| Tuesday before the set-the-week card | Assistant | One brief: lenses 1–12 plus Vegas totals and spreads for our starters. |
| Tuesday card | Blitz | Merge the brief with `playbook/CONSULT.md`. Write the waiver request in `playbook/CLAIMS.md`. |
| Wednesday 2:00 AM | ESPN | Waiver run. |
| Wednesday night | Ken, Consultant | Rank who is still free. Ken says yes or no. |
| Thursday afternoon | Assistant | Availability for any Thursday starter. Blitz sets DST before lock. |
| Friday | Blitz | One MODE tweak if a line or inactive moved. |

## Output

Assistant writes the Tuesday brief to `agents/assistant/work/week-N-pass.md`.
Blitz cites that file on the card.
Consultant writes the Wednesday note in `playbook/CONSULT.md` only after Ken asks in chat.
