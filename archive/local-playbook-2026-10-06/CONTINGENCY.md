# Tight-spot contingency — Quantum Blitz

**Owner:** Blitz (Ken face). Recon = trade/WW intel; Sigma = ranks/slates; Wire = availability.
**Trigger (proactive — do not wait for Ken):** sole startable QB OUT/IR; multi-week starter OUT with thin depth; empty mandatory slot before first kickoff; similar roster emergency.

## Discover
1. Wire AV + ESPN injury tags → confirm hole length (days vs weeks vs season).
2. ESPN FA/WW pool for that slot (status FREEAGENT vs WAIVERS; our rank; process time CT).
3. Sigma: rank holds vs bridges on **this week**, **next 3**, **ROS**.
4. Recon/Blitz roster scan: every team’s surplus at the hole position; their OUT/IR itches; our surplus chips; schedule threat (next matchup + PF).

## Evaluate → recommend or no-recommend
| Path | Use when | Watch outs |
|------|----------|------------|
| Waiver #1 | Best available upgrade on WW | Priority; contested heat |
| Waiver #2 seatbelt | #1 may fail; same drop OK | Does **not** spend trade chips |
| FA grab post-process | Claim missed; player cleared WW | First-come after process — be awake or pre-filed #2 |
| Hold / no move | Spot filled; upgrades don’t beat cost | Say **no-recommend** plainly |
| Trade | WW thin; rival has surplus starter-quality backup | Prefer **lower threat**; never arm **this week’s opponent** before their games; soft-touch until waiver resolves if claim is Plan A |
| Dual-QB flex | Season-long hole; two styles | Bench cost; plan to trade spare later |

## Timing
- **Want first:** best free/WW path (claim ladder).
- **Binding trade:** after claim result, unless Ken accepts certainty over upside.
- Soft trade texts pre-process OK if framed as contingency.

## Ken output (always)
- Hole + deadline + waiver rank
- Ranked options with Pos · NFL team · role
- Threat note if trading
- Clear **recommend** or **no-recommend**
- Copy-paste command only when action needed — still wait for Ken’s type
- Never auto-claim / auto-trade

## Example (W3 2026)
Dart OUT → claim Murray drop Brooks + optional Geno #2; FA devil’s-advocate Shough already rostered; trade scout PP/Shough (high threat — play W3) vs LY/Baker (lower threat — W10); prefer waiver then later Baker if season-ending.
